# 工地记工小程序

一个纯本地存储的微信小程序，用来记录建筑工人的每日工时、加班小时和工资统计。

## 项目特点

- 不需要服务器
- 不需要微信云开发
- 适合个人记工或小班组记工
- 代码结构简单，方便二次修改

## 功能

- 工人管理：可添加多个工人
- 工资设置：每个工人可设置固定每天工时、正常日工资、加班每小时工资
- 每日记工：选择日期、工人、正常工时，并选择是否加班
- 备注记录：每条记工记录可填写工地、工作内容等备注
- 记录查看：查看和删除历史记工记录
- 工资统计：按自定义日期范围统计正常工时、加班小时和结算金额
- 快速筛选：统计页支持按月快速筛选
- 数据导出：统计页支持按当前日期范围导出 CSV

## 页面结构

```text
pages/index    每日记工
pages/records  历史记录
pages/stats    工资统计
pages/workers  工人设置
```

## 工资计算

正常工资 = 正常工时 / 固定每天工时 * 正常日工资

加班工资 = 加班小时 * 加班每小时工资

总工资 = 正常工资 + 加班工资

## 使用方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本仓库根目录。
4. AppID 可先选择测试号或使用自己的小程序 AppID。
5. 编译运行。

详细搭建步骤见 [SETUP.md](SETUP.md)。

## 数据说明

当前版本不使用服务器和云开发，所有数据都保存在微信本地缓存中。删除小程序缓存或换手机后，本地数据不会自动同步。
